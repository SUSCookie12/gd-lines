## 🔄 Автоматични актуализации (GitHub Pages)

Приложението проверява за нови версии в реално време чрез GitHub Pages:
* `version.json` съдържа номера на актуалната версия, бележките за промените и директния линк за изтегляне.
* GitHub Pages URL: `https://suscookie12.github.io/gd-lines/version.json`

## 🚌 Характеристики на GD Lines

- **100% реални данни в евро (€)**: Актуални маршрути, спирки, часове на тръгване и цени за целия регион на Гоце Делчев.
- **6 дизайнерски цветови теми**: Пълна персонализация на интерфейса в чист дневен Light режим (Lime Soda, Ultraviolet, Solar Flare, Glacier, Cobalt Rose, Mesta Pine).
- **Тактилни 3D бутони**: Механично усещане при натискане с haptic вибрация.
- **Потребителски сигнали**: Възможност за подаване на сигнали за закъснения, промени в разписанията и споделяне на снимки от автогари и спирки.
